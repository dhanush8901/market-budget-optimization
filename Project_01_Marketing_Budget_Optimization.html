Marketing Budget Optimization

Problem

Heavy spend across many channels, but management cannot tell which campaigns bring profitable customers. Identify wasted spend, estimate campaign effectiveness and recommend a reallocation.

Algorithm flow

InputProcessDecisionOutput
Collect campaign, customer, conversion & revenue data
Clean & join: spend → leads → customers → revenue
Compute CAC, ROAS, LTV:CAC, profit per channel
Fit response curve per channel (diminishing returns: rev = a·spend^b)
ROAS < target or LTV:CAC < 3 ?
YES → mark channel inefficient, release X% of its budget
NO → candidate for extra budget (ranked by marginal ROAS)
Re-allocate released budget, re-predict revenue with response curves
Recommended budget plan + projected uplift

Pseudocode

for ch in channels:
    ch.cac  = ch.spend / ch.new_customers
    ch.roas = ch.revenue / ch.spend
    ch.b    = fit_loglog(ch.history_spend, ch.history_revenue)   # elasticity
losers  = [c for c in channels if c.roas < TARGET_ROAS]
winners = sorted(others, key=marginal_roas, reverse=True)
pool = sum(c.spend * SHIFT_PCT for c in losers)
for c in losers:  c.new_spend = c.spend * (1 - SHIFT_PCT)
for w in winners: w.new_spend = w.spend + pool * w.marginal_roas / sum_marginal
projected = sum(c.rev0 * (c.new_spend / c.spend) ** c.b for c in channels)
return plan, projected - current_revenue
